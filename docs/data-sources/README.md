# Fuentes de datos

Cada fuente externa integrada en DRIVEAM tiene su propio documento en esta carpeta, creado a
partir de [`_template.md`](_template.md) **antes** de escribir código de integración.

Regla (`PROJECT_VISION.md` §14): nunca se asume que una web puede scrapearse o republicarse
solo porque sea técnicamente posible. La versión personal y la versión pública pueden tener
conjuntos de fuentes distintos.
